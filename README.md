# Sip Me Up 🍒 — Site web

Site vitrine pour **Sip Me Up**, bar à sodas mobile sans alcool pour événements
(Gatineau | Ottawa).

## Contenu

- `index.html` — page unique : à propos, offre, fonctionnement, événements, contact
- `styles.css` — styles (palette crème rayée / rose / vert sauge, responsive)
- `script.js` — menu mobile et année du pied de page

Le bouton « Réserve ta date » pointe vers le formulaire de réservation
Microsoft Forms officiel.

## Lancer le site

Aucune dépendance : ouvrir `index.html` dans un navigateur, ou servir le
dossier avec n'importe quel serveur statique, par exemple :

```bash
python3 -m http.server 8000
```

Le site peut être hébergé tel quel sur GitHub Pages, Netlify, Vercel, etc.
